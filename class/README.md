# Tu dashboard de negocio

22 diapositivas, con una duración propuesta de 24 minutos de explicación. Taller aparte, sin prometer tiempo de instalación.

Desde la raíz del repo: `npm run class:serve`. Abrí http://127.0.0.1:4324. También se puede abrir index.html directamente, aunque el servidor local mejora compatibilidad de ventanas y copiar texto.

- `index.html`: presentación 1920×1080 escalada a pantalla.
- `presenter.html`: notas y cronómetro; abrir con P desde la presentación.
- `speaker-notes.md`: guion legible sin navegador.
- `workshop.html`: guía responsive, prompts copiables y diagnóstico.
- `slides.js`: contenido editable. `class.css`: diagramas y estilos de esta clase.

Teclas: flechas/espacio para avanzar; I índice; P notas; F pantalla completa; M pausar animaciones; B pantalla negra; Home/End inicio/final. Respeta movimiento reducido. Compartí solo la ventana de presentación para no mostrar notas ni secretos. Los enlaces externos abren otra pestaña.

Sistema visual conservado de la clase Segundo Cerebro Avanzado: hueso/índigo, Fraunces + Hanken Grotesk, lienzo 1920×1080, jerarquía editorial, diagramas y motor de presentación. Diagramas de este material creados con HTML/CSS; no contiene capturas ni cifras privadas. Fuentes locales y licencias OFL en assets/. Sin dependencias de CDN.

El contenido explica funciones y límites del kit actual; antes de dar la clase, revisá README.md, docs/integrations.md, docs/security.md, docs/utmify.md y docs/decision-checklist.md del repositorio. Una afirmación comercial de un proveedor no equivale a una auditoría técnica.
